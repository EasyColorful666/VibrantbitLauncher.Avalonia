# VibrantbitLauncher

**轻量、快速、现代的 Minecraft Java 版启动器。**

从下载第一个版本到和朋友一起开服，全部在一个窗口里完成。

---

## 一句话介绍

> 一个不用折腾的 Minecraft 启动器：装版本、装模组、装整合包、找朋友联机，
> 都在同一个界面里点几下就好。

## 功能一览

### 账户

- 支持微软账户、外置账户（第三方验证服务器）、离线账户
- 启动时自动恢复上次使用的账户，不用每次重新登录
- 账户换肤、头像与皮肤预览
- 正版账户与离线账户可同时保存，随时切换

### 版本

- 原版全版本下载，含正式版、快照、远古版、愚人节版，可按类型筛选
- 一键安装 Fabric / Forge / NeoForge / Quilt
- 版本隔离：每个版本用独立的存档、模组与配置，互不干扰
- 启动前自动体检，缺文件时弹窗说明，只补缺的那部分
- 自带 Java 运行环境下载，装到标准位置，其它启动器也能复用

### 启动

- 自动匹配与手动选择 Java，列出机器上每一个已安装的 Java
- 内存、附加启动参数、全屏、窗口大小、内存回收方式均可调
- 记住每个版本的设置，下次直接启动

### 模组与整合包

- 内置资源浏览：模组、光影、整合包、资源包、数据包
- 资源简介自动翻成中文，不用看懂英文也能挑
- 一键「添加到实例」，直接下到对应版本的模组目录
- 整合包拖进窗口即装：自动装好对应游戏版本、加载器与全部模组
- 安装进度可查看每个文件的下载状态，可随时取消

### 修与分享

- 模组依赖体检：缺什么、重复什么一目了然，可一键补齐
- 配装码：把整套模组压成一段短码，发给朋友即可复刻
- 崩溃一键修复：自动调整内存、切换到匹配的 Java、禁用可疑模组

### 联机

- 内置组网功能，房主生成密钥、房客粘贴即可加入
- 一键安装局域网联机模组，开房时直接关闭正版验证，离线账号也能进
- 支持自定义端口与公网映射

### 界面

- 亮色 / 暗色主题，强调色可自定义
- 窗口、页面、列表都有动效；性能模式下自动关闭
- 性能模式：低配电脑一键切换，界面更朴素但更流畅

## 支持的平台

Windows（x64 / x86 / ARM64）、Linux（x64 / ARM64）、macOS（Intel / Apple 芯片），共 7 个平台。

Windows 版提供**免安装的单文件程序**，不需要安装过程，解压或直接双击即可运行。

---

## 第一次使用

1. **选游戏目录** —— 存档、模组、配置都会放在这里，之后随时可改
2. **选 Java** —— 自动检测；没装也可以在启动器里直接下载
3. **登录账户** —— 正版、外置、离线都可以，也可以先跳过

之后在「下载」里装一个版本，回到启动页点「启动游戏」即可。
