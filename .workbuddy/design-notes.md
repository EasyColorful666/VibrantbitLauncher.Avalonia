# Vibrantbit Launcher · 界面设计说明（1.0.12.0）

## 一句话

整窗只有一种视觉语言：**层**。画布 → 极光 → 玻璃 → 卡片 → 强调，五层之间
靠「透明度 + 1px 细线 + 一道浅影」区分，不靠颜色堆叠。

## 三格协议（每次改版必须能填满）

### ① 主角 —— 启动页的「启动游戏」

全屏唯一带光晕、唯一 52px 高、唯一渐变填充的控件。
其他按钮全部降级成无底无边的文字按钮（`Classes="subtle"`），
主色面积控制在 8% 以内。**一屏只能有一个东西发光。**

### ② 母题 —— 「层」（Layered）

母题落在三类控件上，不是贴在某一处：

| 控件 | 层怎么体现 |
| --- | --- |
| 卡片 | 实心面压在半透明玻璃之上 + 1px 细线 + 双层阴影（贴边一层定边、散开一层定高度） |
| 导航 / 分类栏 | 与内容同底，靠选中胶囊与字重区分，不再切一条色块把窗口劈开 |
| 浮层 / 弹窗 | 压暗遮罩 + 12px 圆角玻璃卡片，从 96% 弹到 100% |

### ③ 标志性瞬间 —— 主按钮背后的呼吸光晕

径向渐变从主色 55% 衰减到全透明，3 秒一个来回，只有 0.35↔0.85 的透明度变化。
它是**全应用唯一的循环动画**：不动布局、不重绘渐变、不改颜色，
在任何机器上都只是合成一帧透明度。

## 数值（改之前先看这张表）

| 维度 | 取值 |
| --- | --- |
| 字号 | 32 / 22 / 17 / 14 / 12（严格 5 档，相邻级差 ≥1.45） |
| 图标 | 12 / 16 / 24 / 32 / 44 / 64（独立一档阶梯，不参与文字层级） |
| 圆角 | 4（控件）/ 8（卡片）/ 12（面板与浮层）/ 胶囊（只给一次性强调） |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32；组内 8，组间 24 |
| 动效 | 100（反馈）/ 200（转场）/ 300（入场），全部落在 50ms 网格 |
| 缓动 | 进 CubicEaseOut、出 CubicEaseIn、按压 BackEaseOut（轻微过冲） |
| linear | 只允许进度条与加载环 |

## 反众数（只反在结构上，不反在装饰上）

1. **不用「左导航 + 顶栏 + 三张等宽卡」的模板壳**：右侧快捷设置是一整块面板 + 两条 1px 分割线，
   不是三张卡。三块等大的框会把视线摊平。
2. **不用「居中大标题 + 副标题 + 两个按钮」的引导页**：页头一律左对齐，
   只用 28×2 的主色短横做锚点。

## 性能取舍（给低端机留的门）

- 极光是**静态**的。三块 700~960px 径向渐变一旦逐帧换位，Avalonia 会整层重绘，
  低端核显上吃掉 10%~20% 的 GPU，而它表达的信息量是零。
- 全屏只有 1 处无限动画（主按钮光晕），且只动透明度。
- 「设置 → 个性化 → 性能模式」会把所有过渡、缩放、阴影、光晕、列表飞入一起清零，
  由根节点的 `performanceMode` 类统一开关。

## 1.0.27.0 · 明亮清爽（现行）

上面那些是「深色沉浸」时代的取舍，已作废，留作历史。

### 三句话

1. **白是底色，不是留白。** 画布纯白，内容靠字号、字重、间距分层。
2. **线只用来圈住可点的东西。** 卡片有 1px 浅描边，区域之间**没有**分割线。
3. **不动。** 按钮不缩放，卡片悬停不抬阴影，页面切换只上浮 8px。

### 为什么砍掉阴影

投影的作用是「让物体看起来离开了底面」。在深色界面里，底和面亮度接近，
投影是唯一能表达高度的东西；纯白界面里卡片和画布同一个白，
投影就只剩一圈灰边 —— 看着像没擦干净的屏幕。

### 为什么砍掉极光

三块巨大的径向渐变在深色里是氛围，在白底上会把整窗染成不均匀的灰。
「明亮清爽」的反面不是「暗」，是「脏」。

### 为什么页头没有强调色

以前标题下面有一道 20×3 的主色短横。它确实是个视觉锚点，
但它把「标题」和「说明」这两行本该连读的字切成了三段。
层级已经在字号上了（28 vs 12），不需要再加一道线。

### 强调色的三条边界

- 主按钮实心（全页只有一颗）
- 当前选中项（侧栏 / 列表一侧）
- 极少数图标

面积超过 8% 就不叫强调色了，叫主色调。

### 圆角

6 控件 / 10 卡片 / 16 浮层 / 胶囊。
16 只给浮层 —— 大面积用大会显得软塌，像贴纸。
