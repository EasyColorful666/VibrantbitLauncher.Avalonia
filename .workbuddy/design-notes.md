# Vibrantbit Launcher · 界面设计说明（1.0.29.0）

## 一句话

整窗只有一种视觉语言：**白、留白、克制**。层级只靠三样东西建立 ——
留白、1px 极浅描边、字重与三级灰。**不用阴影、不用渐变、不用色块。**

## 三格协议（每次改版必须能填满）

### ① 主角 —— 启动页的「启动游戏」

全页唯一的实心色块：46px 高、主色实心、白字 SemiBold，贴左下角。
其余操作全部退成 `.subtle`（无底无边）或白底描边按钮。
主色面积控制在 8% 以内。**一屏只能有一个实心块。**

### ② 母题 —— 「状态」（State）

界面里唯一允许动的是**状态**，不是物体：白底上任何大幅度位移与缩放都会显得界面不稳。
母题落在三类控件上，不是贴在某一处：

| 控件 | 状态怎么体现 |
| --- | --- |
| 按钮 / 列表行 | 悬停换底色（100ms）、按住回缩 1.5%、松开回弹；不位移、不换位置 |
| 卡片 | 悬停只加深那一根 1px 描边；只有整块可点的内容卡（`.lift`）才上浮 2px |
| 页面 / 浮层 | 旧内容 150ms 先走、新内容 250ms 后落定；分类切换带左右方向 |

### ③ 标志性瞬间 —— 「列表一条条落定」

进任何一页，列表不是整块出现，而是按 20ms 间隔一条条从左侧 24px 处落定，
最多错开 12 项；页面本身在同一时间只做「淡出 + 上浮 12px」。
两段节奏叠起来是一屏里唯一的大动作 —— **同屏同刻只允许一个"大动作"**，
所以进度条一启动，列表就不再播入场。

## 动效（1.0.29.0 全站统一）

| 类别 | 时长 | 曲线 | 用在哪 |
| --- | --- | --- | --- |
| 反馈 | 100ms | `EaseFeedback` (0.33,0,0.67,1) | 悬停 / 按住 / 选中 / 聚焦，只动颜色 + 1.5% 回缩 |
| 转场 · 进 | 250ms | `EaseEnter` (0.05,0.7,0.1,1) | 页面、分类、列表项、浮层落定 |
| 转场 · 出 | 150ms | `EaseExit` (0.3,0,1,1) | 旧页面、浮层、通知退场（**出永远比进短**） |
| 窗口 · 进 | 300ms | `EaseEnter` | 主窗口、向导、内嵌子页飞入 |
| 窗口 · 出 | 200ms | `EaseExit` | 关窗先飞出再真正关闭 |
| 循环 | 2s / 24s | `SineEaseInOut` | 联机状态点呼吸 / 壁纸呼吸，**二选一** |

**位移只有三处**：按住回缩 1.5%、列表逐项 24px、页面与窗口 12px。
**linear 只给进度条**（下载的真实进度），其余一律非线性。

三档可关：完整 / 精简（只留颜色）/ 关闭（一帧不播，性能模式同此）。
XAML 侧是窗口根节点的 `.performanceMode` / `.motionReduced` 类，代码侧是 `MotionSettings`。

## 反众数（只反这两条）

- **不靠阴影做层次**：全站只有浮层（`Border.glass` / `InlineHostOverlay`）有投影，
  卡片永远只有 1px 描边。这样一屏可以放十几张卡而不显脏。
- **不给每个元素都加动效**：动效只回答「我点到了 / 我从哪来 / 它还在跑」，
  回答不了的一律不加。留白比动效更能表达高级。
